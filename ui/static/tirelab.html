Model assumptions and calibration

This is a tuning prototype using an MF5.2-style force evaluator and an approximate vehicle model. Geometry and mass cannot identify an entire real tire dataset. The calculator changes nominal per-wheel load, radius and peak friction while retaining the supplied normalized stiffness and curve shape. Pressure deformation uses a simple carcass approximation; temperature, wear, suspension kinematics and road-surface friction are not solved. Validate generated configurations in Reforger's Pacejka Plot Tool and driving tests.
